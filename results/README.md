# Results

Every training run writes `<experiment>/fold<k>/<Model>.json` (k = official patient-wise test fold) containing the
full recipe, the per-epoch history, the selected epoch, test metrics, and the validation and test probabilities.
All experiments use the official patient-wise 5-fold split of the Figshare dataset.

## Experiment index

| Prefix | Classes | Training data | What it is |
|---|---|---|---|
| `cv3_baseline`, `cv4_baseline` | 3 / 4 | 3 folds | four models with the baseline recipe (AdamW 1e-4, resize only, 15 epochs) |
| `cv3_improved`, `cv4_improved` | 3 / 4 | 3 folds | four models with the improved recipe |
| `cv3_attn`, `cv4_attn` | 3 / 4 | 3 folds | improved + Grad-CAM guidance (InceptionV3/EfficientNet-B3: first loss form `outside_ratio`; AlexNet: released form) |
| `cv3_attn448` | 3 | 3 folds | guided EfficientNet-B3 / InceptionV3 at 448 px (resolution ablation) |
| `p3_full_*` | 3 | 3 folds | guided full-image EfficientNet-B3 / InceptionV3, seeds 42 (no suffix), 1 (`_s1`), 2 (`_s2`) |
| `p3_convnext384_ema*`, `p3_effv2s384_ema*` | 3 | 3 folds | guided ConvNeXt-T / EfficientNetV2-S at 384 px with EMA weights, 3 seeds |
| `p3_effb3_ema` | 3 | 3 folds | guided EfficientNet-B3 with EMA weights (EMA ablation) |
| `p3_roi2_*`, `p3_roi3_effb3` | 3 | 3 folds | guided tumor-region classifiers, crop context 2× (3 seeds) / 3× |
| `refit_*_s{42,1,2}` | 3 | **4 folds** | the validation-selected configurations refit on all non-test folds (final models) |
| `seg_cv` | – | 3 folds | Mask R-CNN segmentation (`maskrcnn.json` per fold) |
| `boxes/` | – | – | out-of-fold Mask R-CNN boxes used by the tumor-region classifiers |
| `gradcam/<experiment>/` | – | – | Grad-CAM localisation summary (`summary.csv`) and fold-1 example figures |
| `selection/` | – | – | validation-based selections (`sel_*.json`) and scores of fixed ensembles (`refit_*.json`) |

`summary.md` / `summary.json` are generated by `scripts/summarize.py` (mean ± std over folds, pooled metrics,
per-class recall).

## Final result

`selection/refit_ensemble.json`: uniform average of the 9 refit models
(`refit_effb3_full`, `refit_incv3_full`, `refit_effb3_roi2` × seeds 42/1/2), chosen in
`selection/sel_groups_val.json` on validation accuracy only — **97.64 ± 1.12 %** test accuracy (3 classes).
